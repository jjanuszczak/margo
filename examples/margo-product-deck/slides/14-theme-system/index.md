## Everything visual lives in a theme.

{{< columns >}}
{{< column >}}
### Theme building blocks

- **Assets** for CSS, fonts, JavaScript, and images
- **Layouts** for deck and slide structure
- **Partials** for reusable template fragments
- **Shortcodes** for author-facing content components
{{< /column >}}
{{< column >}}
### Share and reuse

Keep a theme in a Git repository for maintained installs, or package one as a portable `.margot` archive for a fixed handoff.

`margo theme add` installs a theme. `margo theme pack` makes it easy to move between decks.
{{< /column >}}

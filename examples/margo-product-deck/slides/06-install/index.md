## Be up and running in seconds

Install margo on MacOS, Windows, or Linux ([Omarchy!](https://omarchy.org/)):

### Install using Go
Install the latest tagged version with Go:

`go install github.com/jjanuszczak/margo/cmd/margo@latest`

### Install via Homebrew
MacOS and Linux users can also install through the personal Homebrew tap:

`brew install jjanuszczak/margo/margo`

For prebuilt binaries, download the archive for your platform from the [GitHub Releases](https://github.com/jjanuszczak/margo/releases) page and verify it with the published checksums.txt file.

## A lightning fast Hugo-inspired presentation engine

The malleable slideware for the age of agents. Compiles pure Markdown into beautifully styled, highly scriptable slide decks.

{{< columns >}}
{{< column variant="plain" >}}

### Built for agents **and** humans

- Write content in markdown
- Build and share reusable themes in html and css
- Decks are portable (git) repositories
- Agentic out of the box: new decks come with agent instructons and skills

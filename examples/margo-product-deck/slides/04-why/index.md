## Presentation work belongs in the same workflow as the work it explains.

Most teams still rebuild context in a slide editor, then lose the review trail, reuse path, and source of truth.

{{< columns >}}
{{< column >}}
### The old loop

- Copy content into a visual editor
- Recreate layouts by hand
- Share a file with unclear provenance

{{< /column >}}
{{< column >}}
### The Margo loop

- Author in Markdown
- Preview locally with `margo serve`
- Build a versioned artifact

{{< /column >}}
{{< /columns >}}

*One source of truth: content, theme, assets, notes, and release history live together.*
